# Project logo

An original painted fantasy-item logo. Generated using the built-in image generation tool.

- `logo-1024.png`: 1024px square, for the CurseForge project page.
- `logo.png`: 512px square export.
- `logo-master.png`: full-resolution generated master; resize this for future exports.
- `logo-prompts.json`: the generation prompt and reference.

The website icons are generated from `logo-1024.png` by `apps/web/scripts/icons.ts`; these files are the addon project logo (the companion app, Ravenpost, has its own repository).
