# Project logo

An original painted fantasy-item logo inspired by the visual style of [Archivist for Forever](https://www.curseforge.com/wow/addons/archivist-for-forever). Generated using the built-in image generation tool.

- `logo-1024.png`: 1024px square, for the CurseForge project page.
- `logo.png`: 512px square export.
- `logo-master.png`: full-resolution generated master; resize this for future exports.
- `logo-prompts.json`: the generation prompt and reference.

The website and companion app icons remain in their existing locations; these files are the new addon project logo.
